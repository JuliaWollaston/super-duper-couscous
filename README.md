# 🍅 Pomodoro Timer - 番茄工作法计时器

一个简洁优雅的番茄工作法时间管理工具，帮助您提升专注力和工作效率。

## ✨ 功能特点

### 计时器
- 🍅 专注工作计时（默认25分钟）
- ☕ 短休息计时（默认5分钟）
- 😴 长休息计时（默认15分钟，每4个番茄后）
- ⏯️ 开始/暂停/重置控制
- 🔔 计时结束声音提醒
- 💬 浏览器通知提醒

### 任务管理
- ✅ 添加/编辑/删除任务
- 📊 任务进度追踪
- 🎯 设置目标番茄数

### 统计数据
- 📈 今日/本周/本月统计
- 📊 完成番茄数统计
- ⏰ 工作时长统计
- 📉 周统计图表

### 自定义设置
- ⚙️ 自定义工作时长（1-60分钟）
- ⚙️ 自定义休息时长（1-30分钟）
- ⚙️ 自定义长休息时长（1-60分钟）
- ⚙️ 自定义长休息间隔（1-10个番茄）

### 快捷键
- `Space` - 开始/暂停计时器
- `R` - 重置计时器
- `N` - 新建任务

## 🚀 使用方法

### 在线使用
直接打开 `index.html` 文件即可使用，无需服务器支持。

### 本地开发
```bash
# 克隆项目
git clone https://github.com/yourusername/pomodoro-timer.git

# 进入项目目录
cd pomodoro-timer

# 使用浏览器打开
open index.html
```

### 部署到服务器
将项目文件上传到您的Web服务器即可运行。

## 🛠️ 技术栈

- **前端**: HTML5 + CSS3 + JavaScript (ES6+)
- **数据库**: IndexedDB (浏览器本地存储)
- **图表**: Chart.js (CDN引入)
- **样式**: 响应式设计，支持PC和移动端
